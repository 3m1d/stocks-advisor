## 🎯 О проекте

**Тема:** Разработка сервиса, дающего инвестиционные рекомендации (покупать/продавать/ничего не делать) в краткосрочной перспективе (горизонте недели) по активам Российского фондового рынка.

---

## 📋 План разработки

1.  Знакомство с командой и куратором, определение темы работы, источников данных, изучение аналогов, создание репозитория проекта

2. Парсинг данных из выбранных источников, разведочный анализ данных, приведение данных к правильному формату

3. Разработка базовой модели на основе технического анализа для рекомендации активов к покупке

4. Разработка модели, использующей данные технического анализа и текстовые данные из источников

5. Разработка сервиса (сайт) с требуемым функционалом

6. Разработка нейросетевых моделей для рекомендации активов к покупке

7. Добавление нового функционала в сервис, улучшение существующих подходов к предсказаниям
