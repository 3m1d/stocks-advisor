### Пайплайны для ETL

`news_pipeline.py` - конкатенация нескольких датасетов с новостями и генерация признаков
Признаки:
- `tickers` - список тикеров: выделение именованных сущностей из текста новости -> поиск среди них названий интересующих компаний (голубые фишки) -> преобразование в тикеры
- `sector` - индекс сектора влияния новости или `NULL`: векторизация ключевых слов для индексов секторов экономики (индексы MOEX) -> векторизация текста новости -> поиск сектора максимального косинусного сходства (если оно < 0.1 - NULL)
- `text_sentiment` - тональность новости (negative / neutral / positive) - применение fine-tuned (на новостях фин. рынка) модели для определения тональности

Usage: news_pipeline.py [OPTIONS] [INPUT_FILES]...

Options:
  --out_raw TEXT      Выходной необработанный csv файл
  --out TEXT          Выходной обработанный csv файл
  -t, --test INTEGER  Размер тестовой выборки (если 0 - обработка целиком)
  --help              Show this message and exit.

Пример использования:
```bash
python news_pipeline.py ./*.csv --out_raw=or.csv --out=o.csv -t 400
# конкатенация всех csv файлов в директории -> запись в or.csv
# применение пайплайна на рандомной выборке из 400 записей -> запись результата в o.csv
```
